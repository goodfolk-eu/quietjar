# 09: How do I add a donation button to my Astro or Hugo static site?

Adding a donation button to an Astro or Hugo static site is straightforward. You don't need a backend, database, or server-side payment processing.

The easiest approach is to use a hosted donation service that handles payments for you, then add its URL to a button on your website.

There are three good approaches:

Stripe Payment Links – best if you want a professional donation experience and control over amounts.

Ko-fi or Buy Me a Coffee – best for quick, simple donations and tips.

GitHub Sponsors – best for open-source projects.

## 1. The simplest option: hosted donation link

For example, create a donation page with Ko-fi or Stripe.

You'll receive a URL such as:

text

```
https://ko-fi.com/yourname
```

Then add a button to your site.

## 2. Add the button to Astro

Create a reusable Astro component:

src/components/DonateButton.astro

astro

```
---
interface Props {
  href?: string;
  label?: string;
}

const {
  href = "https://ko-fi.com/yourname",
  label = "Buy me a coffee"
} = Astro.props;
---

<a
  href={href}
  class="donate-button"
  target="_blank"
  rel="noopener noreferrer"
>
  ♥ {label}
</a>

<style>
  .donate-button {
    display: inline-block;
    padding: 12px 24px;
    background: #e85d75;
    color: white;
    text-decoration: none;
    border-radius: 8px;
    font-weight: 600;
    transition: background 0.2s ease;
  }

  .donate-button:hover {
    background: #cf4560;
  }
</style>
```

Use it anywhere:

astro

```
---
import DonateButton from "../components/DonateButton.astro";
---

<DonateButton />

<DonateButton
  href="https://ko-fi.com/yourname"
  label="Support this project"
/>
```

## 3. Add the button to Hugo

Hugo uses Go templates, so you can create a reusable partial.

Create:

layouts/partials/donate.html

HTML

Wrap linesCopy codePreview

```
<a
  href="{{ .Site.Params.donationURL }}"
  class="donate-button"
  target="_blank"
  rel="noopener noreferrer"
>
  ♥ Support this project
</a>
```

Add the URL to your hugo.toml:

toml

```
[params]
  donationURL = "https://ko-fi.com/yourname"
```

Then include the partial in any template:

go-html-template

```
{{ partial "donate.html" . }}
```

Add the CSS to your stylesheet:

css

```
.donate-button {
  display: inline-block;
  padding: 12px 24px;
  background: #e85d75;
  color: white;
  text-decoration: none;
  border-radius: 8px;
  font-weight: 600;
}

.donate-button:hover {
  background: #cf4560;
}
```

## 5. Which approach would I recommend?

For a static site, I'd choose:

Requirement

Recommendation

Simplest possible button

Ko-fi

One-time and recurring donations

Stripe or Ko-fi

Custom payment amounts

Stripe

Open-source project

GitHub Sponsors

No third-party backend to maintain

Hosted payment link

My recommendation: Start with a normal HTML button pointing to a hosted donation page. It's lightweight, works with both Astro and Hugo, requires no JavaScript, and won't affect your site's performance.

One important security rule: never put Stripe secret keys or other payment credentials in your static site's frontend code.
