# 07: How do I add a donate button to my WordPress site without using PayPal?

You can easily add a Donate button to your WordPress website without using PayPal. There are several alternatives that let visitors donate directly using credit cards, debit cards, iDEAL, Apple Pay, Google Pay or other payment methods.

The best option depends on whether you want a simple one-time donation button or a complete donation system with recurring donations.

## 1. Best alternatives to PayPal

Stripe

Great for simple donation buttons and card payments. Supports Apple Pay and Google Pay, with iDEAL available for eligible Dutch transactions.

Best for straightforward donations

Stripe website

Mollie

Particularly good if your visitors are in the Netherlands or Europe. Supports iDEAL, credit cards, Bancontact and other payment methods.

Best for Dutch and European donations

Mollie website

GiveWP

A dedicated WordPress donation plugin. Lets you create donation forms, suggested amounts, donor records and recurring donation options. Payment gateways depend on the integration you choose.

Best for a dedicated donation page

GiveWP website

## 2. How to add a Donate button using GiveWP

This is probably the easiest way if you want a professional-looking donation button.

6

Follow these steps:

Log in to your WordPress dashboard.

Go to Plugins → Add New Plugin.

Search for GiveWP.

Click Install Now, then Activate.

Open the GiveWP menu and create a new donation form.

Set suggested donation amounts, for example €5, €10, €25 and €50.

Connect your Stripe account (or another supported payment gateway).

Save and publish your donation form.

Add the donation form to your Donate page using the GiveWP block.

You can also put a Donate button in your website's navigation menu or homepage.

GiveWP supports Stripe in its free plugin, although some payment features and additional fees may depend on your plan.

## 3. If you want to use Mollie instead

If you're based in the Netherlands, I'd also consider Mollie.

There's a WordPress plugin called Doneren met Mollie, which supports one-time and recurring donations using Mollie's payment methods.

You can find it here: WordPress plugin directory (search for "Doneren met Mollie").
