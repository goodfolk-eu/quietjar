# 07: How do I add a donate button to my WordPress site without using PayPal?

You have several good non-PayPal options. Here are the most common, from easiest to most flexible:

## 1. Stripe Payment Link (no plugin needed)
1. Create a free Stripe account.
2. In the Dashboard, go to **Payment Links → New**, and choose **Customers choose what to pay** (or set a fixed amount). Recurring donations are also supported.
3. Copy the link.
4. In WordPress, add a **Button block** in the editor, paste the link as the URL, and label it "Donate."

This is the simplest approach. Stripe hosts the checkout, so you don't handle card data.

## 2. A donation plugin
- **GiveWP**: the most popular dedicated donation plugin. It has a free core with Stripe support, donor management, receipts, and recurring gifts (some features are paid add-ons).
- **WP Simple Pay**: Stripe-focused, with a lighter setup.
- **Charitable**: a GiveWP alternative with a free tier.
- **Jetpack**: includes a Donations block (it uses Stripe via Jetpack's connection).

Install via **Plugins → Add New**, connect your payment processor, then add the donation form with a block or shortcode.

## 3. Other platforms with embeddable buttons
- **Ko-fi** or **Buy Me a Coffee**: quick for creators, with a widget or link.
- **Liberapay**: for recurring donations, and open-source friendly.
- **Open Collective**: good for projects or groups needing transparency.
- **Zeffy**: free for nonprofits, with no platform fees (it relies on optional donor tips).
- **Square**: if you already use it, you can generate a donation payment link.

## 4. Crypto (optional)
Coinbase Commerce or similar services can generate a button or link.

## Tips
- Check **fees**: Stripe charges about 2.9% + 30¢ per transaction in the US, and some platforms add their own fees.
- If you're a registered nonprofit, look at nonprofit discounts and tax-receipt features.
- Test a small donation before launching.
- Put the button in a visible spot, such as the header, sidebar widget, or the end of posts.
