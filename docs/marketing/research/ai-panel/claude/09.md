# 09: How do I add a donation button to my Astro or Hugo static site?

A static site can't process payments itself, so the button links to or embeds a hosted service. Astro and Hugo handle it the same way.

## 1. Pick a service

| Service | Best for | How it works |
|---|---|---|
| **Buy Me a Coffee / Ko-fi** | Easiest setup, with a ready-made button | Link or widget script |
| **GitHub Sponsors / Open Collective** | Open-source projects | Link |
| **Stripe Payment Links** | Custom amounts and your own branding | Link to a hosted checkout page |
| **PayPal Donate button** | Familiar to most donors | Link or form snippet |
| **Liberapay** | Recurring donations, low fees | Link or widget |

The simplest option with all of them is a plain link styled as a button. You create a payment link or page on the service and paste its URL into your site.

## 2. Astro

Create `src/components/DonateButton.astro`:

```astro
---
const { href = "https://buymeacoffee.com/yourname", label = "☕ Support my work" } = Astro.props;
---
<a class="donate" href={href} target="_blank" rel="noopener noreferrer">{label}</a>

<style>
  .donate {
    display: inline-block;
    padding: 0.6rem 1.2rem;
    background: #ffdd00;
    color: #000;
    border-radius: 6px;
    text-decoration: none;
    font-weight: 600;
  }
  .donate:hover { filter: brightness(0.95); }
</style>
```

Then use it in a page or layout:

```astro
---
import DonateButton from "../components/DonateButton.astro";
---
<DonateButton />
```

## 3. Hugo

Create a shortcode at `layouts/shortcodes/donate.html`:

```html
{{ $href := .Get "href" | default "https://buymeacoffee.com/yourname" }}
{{ $label := .Get "label" | default "☕ Support my work" }}
<a class="donate" href="{{ $href }}" target="_blank" rel="noopener noreferrer">{{ $label }}</a>
```

Use it in any Markdown file:

```
{{< donate >}}
{{< donate href="https://ko-fi.com/yourname" label="Donate on Ko-fi" >}}
```

To put it on every page, add the same HTML to a partial such as `layouts/partials/footer.html`. Add the CSS to your stylesheet.

## 4. Stripe Payment Links (custom amounts)

1. In the Stripe Dashboard, go to **Payment Links → New**.
2. Choose **Customers choose what to pay**, or set a recurring price.
3. Copy the `https://buy.stripe.com/...` URL and use it as the `href` above.

You don't need a backend, and Stripe hosts the checkout page.

## 5. Tips

- **Embedded widgets:** Buy Me a Coffee and Ko-fi give you a `<script>` snippet. In Astro, put it in a component with `<script is:inline>` or add it to your layout. In Hugo, paste it into a partial. Widgets add third-party JavaScript, which affects performance and privacy. A plain link avoids both.
- **Placement:** Put the button in the footer, at the end of blog posts, and on an "About" or "Support" page.
- **Accessibility:** Use descriptive link text, keep color contrast high, and keep `rel="noopener noreferrer"` on external links.
- **Legal:** Some regions require you to disclose that donations aren't tax-deductible, or to register as a charity. Check this if you're collecting money regularly.
