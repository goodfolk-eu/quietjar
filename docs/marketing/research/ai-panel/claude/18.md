# 18: How do I show a donation goal with a progress bar on my website?

There are two common ways to do this: use your donation platform's built-in widget, or build a simple one yourself.

## Option 1: Use your donation platform's built-in goal bar
Many platforms provide this without any code:
- **Givebutter, Zeffy, GoFundMe Charity, Donorbox, Classy:** Create a campaign, set a goal, and embed the widget (usually an iframe or script snippet) on your site.
- **WordPress:** GiveWP, Charitable, and WP Simple Pay include goal progress bars as blocks or shortcodes. GiveWP, for example, has a "Goal" setting on each form.
- **Shopify, Squarespace, Wix:** These have apps or blocks for donation goals, or you can paste custom HTML (see below).

This route updates automatically as donations come in.

## Option 2: Build it yourself (HTML/CSS/JS)

```html
<div class="goal">
  <div class="goal-text">
    <strong id="raised">$0</strong> raised of <span id="goal">$10,000</span> goal
  </div>
  <div class="bar" role="progressbar" aria-valuemin="0" aria-valuemax="100" aria-valuenow="0">
    <div class="fill" id="fill"></div>
  </div>
  <div class="goal-pct"><span id="pct">0</span>% funded</div>
</div>

<style>
  .goal { max-width: 500px; font-family: sans-serif; }
  .bar { background: #e5e7eb; border-radius: 999px; height: 20px; overflow: hidden; }
  .fill { background: #22c55e; height: 100%; width: 0; transition: width 1s ease; }
</style>

<script>
  const raised = 6500;   // update manually, or fetch from your backend/API
  const goal   = 10000;
  const pct = Math.min(100, Math.round((raised / goal) * 100));

  document.getElementById('raised').textContent = '$' + raised.toLocaleString();
  document.getElementById('goal').textContent   = '$' + goal.toLocaleString();
  document.getElementById('pct').textContent    = pct;
  const fill = document.getElementById('fill');
  fill.style.width = pct + '%';
  fill.parentElement.setAttribute('aria-valuenow', pct);
</script>
```

Even simpler, you can use the native element: `<progress value="6500" max="10000"></progress>`.

### Keeping it up to date
- **Manual:** Edit the `raised` number periodically. This is fine for small campaigns.
- **Automatic:** Fetch the total from your payment provider or backend (e.g., Stripe API, your donation platform's API or webhook) via a small server endpoint, then use `fetch('/api/total')` in the script. Never put secret API keys in front-end code. Have your server call the provider and return only the total.

## Tips
- Show the dollar amount and the percentage.
- Add the number of donors, or a deadline, to create urgency.
- Put the bar near your Donate button.
- Make sure the bar is accessible (the `role="progressbar"` and `aria-*` attributes above help).
