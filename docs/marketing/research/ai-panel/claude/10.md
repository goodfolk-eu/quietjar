# 10: Is there an embeddable donation widget I can put on any website?

Yes. Several services give you a copy-and-paste snippet (an iframe or script tag) that works on any site that accepts custom HTML.

**Options**
- **Donorbox** has popup or inline donation forms. It's set up by pasting code and has guides for WordPress, Wix, Weebly and Squarespace.
- **Give Lively** has a Simple widget that can go anywhere. Its Branded version adds imagery, video and social sharing.
- **Givsum** has branded embeds you paste in without coding. They're built to fit any screen size.
- **Jotform** has a donation widget with an embed code for any page that supports custom HTML.
- **Embeddable** is a no-code builder. It has free templates (donation button, goal tracker, recurring signup) and connects to Stripe. It also pushes submissions to tools like HubSpot or Google Sheets.
- **CAF Giving Widget** is a white-label widget for charities. It's an older product, so check that it's still maintained.

**What to check before choosing**
- **Fees:** the search results didn't include pricing. Platforms often charge a platform fee on top of payment processing fees, so check each vendor's pricing.
- **Embed method:** you want an iframe or HTML snippet that works in your CMS without breaking the layout.
- **Nonprofit status:** some platforms assume you're a registered nonprofit. Others, like Stripe-based builders, are more flexible.
- **Recurring gifts and receipts:** confirm these are supported if you need them.
