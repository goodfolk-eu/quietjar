# 15: How can my open source project pay for its hosting costs?

Here are the main ways open source projects cover hosting costs, from lowest to highest effort.

## 1. Donations and sponsorships
- **GitHub Sponsors**: no fees for individuals, and it sits next to your repo.
- **Open Collective**: transparent public ledger, which donors and companies like. It can also act as a fiscal host, so you don't need your own legal entity.
- **Liberapay**: recurring donations, with no platform fee.
- **Ko-fi / Buy Me a Coffee**: easy for one-off tips.
- **Thanks.dev** and **Tidelift**: pay maintainers based on how much companies depend on your package.

Put a `FUNDING.yml` in `.github/` so GitHub shows a Sponsor button. Mention the funding in your README and on your docs site. Say what the money pays for, such as "$40/month covers the docs server and CI."

## 2. Fiscal hosting (legal and tax handling)
If you want to accept money without forming a company, join a fiscal sponsor:
- **Open Source Collective** (US, via Open Collective)
- **Software Freedom Conservancy**
- **NumFOCUS** (scientific and data projects)
- **Linux Foundation / CNCF / Apache / Eclipse** (for larger projects that meet their criteria)
- **Open Collective Europe** or **Commons Conservancy** (for EU-based projects)

## 3. Get hosting donated or discounted
Often you can avoid the cost entirely:
- **Free hosting**: GitHub Pages, Cloudflare Pages, Netlify, Vercel and GitLab Pages cover static sites and docs.
- **Open source programs**:
  - Cloudflare's Project Alexandria
  - AWS Open Source Credits
  - DigitalOcean's open source credits
  - Microsoft Azure credits
  - Google Cloud credits
  - Fastly's free CDN for open source
  - Netlify's open source plan
  - Sentry, Algolia DocSearch, and JetBrains licenses
  - Read the Docs, which hosts docs for free
- **Free CI**: GitHub Actions is free for public repos. CircleCI and others have open source tiers.
- **OSS-focused infrastructure**: OSUOSL (Oregon State) and similar university programs host projects for free.

Program terms change often, so check each one's current page before relying on it.

## 4. Earn revenue from the project
- **Sponsor tiers with perks**: logo placement on your site or README, priority issues, and so on.
- **Open core or paid add-ons**: keep the core free and charge for extras.
- **Hosted version (SaaS)**: charge for a managed service. WordPress and Plausible both did this.
- **Paid support, consulting, or training**.
- **Dual licensing**.
- **Bounties** (Algora, Polar, IssueHunt) for specific features.

## 5. Grants
- **Sovereign Tech Fund / Agency** (Germany), which funds critical infrastructure
- **NLnet / NGI** (EU), which funds small to mid-sized projects
- **GitHub Secure Open Source Fund**
- **Open Technology Fund**
- **Alpha-Omega**, for security-focused work

## 6. Reduce the costs
- Use static hosting wherever you can.
- Put a CDN in front of your assets.
- Use free tiers for monitoring and CI.
- Review the bill regularly, and delete old preview environments and unused resources.

## Practical starting point
1. Move what you can to free open source tiers.
2. Set up Open Collective or GitHub Sponsors for the rest.
3. Publish your costs openly.
4. Approach companies that depend on your project and ask them to sponsor it. A direct ask often works best.
