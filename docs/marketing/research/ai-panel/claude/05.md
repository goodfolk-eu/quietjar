# 05: GitHub Sponsors vs Ko-fi vs Open Collective, which should my open source project use?

**Short answer:** Use GitHub Sponsors if the project is small and maintained by one person or a few. Add Open Collective if you need a legal entity, a shared budget, or company sponsors who need invoices. Ko-fi is usually the weakest fit for open source.

| | GitHub Sponsors | Ko-fi | Open Collective |
|---|---|---|---|
| **Best for** | Individual maintainers, GitHub-centric projects | One-off tips, creators with merch or commissions | Multi-maintainer projects, transparent team budgets |
| **Fees** | Very low or none for personal sponsorship (payment processing may apply in some cases) | 0% platform fee on donations, but PayPal/Stripe fees apply | About 10% host fee (e.g. Open Source Collective) plus processing fees |
| **Fiscal hosting / legal entity** | No. Money goes to a person or org. | No | Yes. The host holds funds, issues invoices, and handles taxes and expenses. |
| **Corporate friendliness** | Good, and sponsors can pay through GitHub billing | Weak | Strong, with invoices, receipts and public ledgers |
| **Discoverability** | Sponsor button on repo, profile and `FUNDING.yml` | Separate site, so you need to bring your own audience | Moderate, with a public project page |
| **Shared funds / paying contributors** | Limited | No | Yes, via expense submission |

**How to choose**
- **Solo maintainer or hobby project:** GitHub Sponsors. It has the lowest friction and the lowest fees, and your users are already on GitHub.
- **Several maintainers, or you want to pay contributors transparently:** Open Collective. The 10% fee buys you fiscal hosting, which is the hard part to set up yourself.
- **Companies are your likely funders:** Open Collective or GitHub Sponsors. Both can produce invoices and receipts, which procurement teams often require.
- **Casual "buy me a coffee" tips from a broad audience:** Ko-fi works, but it's mainly designed for creators rather than software projects.

You can also combine them. List several platforms in `.github/FUNDING.yml`, for example GitHub Sponsors for individuals and Open Collective for the project itself. GitHub shows them all in the Sponsor button.

**Caveat:** Fees, eligible countries and host terms change often, and I didn't check live pricing. Confirm the current numbers on each platform's site before committing. Payout availability also depends on your country.
