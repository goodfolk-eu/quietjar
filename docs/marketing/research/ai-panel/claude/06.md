# 06: How do I add a donate button to my website?

There are a few ways to do it, from quickest to most customizable.

## 1. Use a payment link or hosted button (easiest, no code)
Most donation platforms generate a button or link for you:

- **PayPal**: Go to PayPal's "Donate button" tool, set up your button, and copy the HTML it gives you.
- **Stripe**: Create a **Payment Link** (Dashboard → Payment Links), then enable "Let customers choose what to pay" for donations.
- **Ko-fi / Buy Me a Coffee / Liberapay**: Create a profile and paste their button or widget snippet.
- **Nonprofit platforms** (Givebutter, Donorbox, Zeffy, GiveWP): These offer embeddable forms, recurring gifts, and receipts. Zeffy is free for registered nonprofits.

## 2. Add it to your site
Once you have a link, a basic button is just:

```html
<a href="https://your-donation-link-here"
   target="_blank" rel="noopener"
   style="display:inline-block;padding:12px 24px;background:#2563eb;color:#fff;
          border-radius:6px;text-decoration:none;font-weight:600;">
  Donate
</a>
```

If you paste in an embed snippet from a platform, use your site builder's "Custom HTML" or "Embed" block.

**By platform:**
- **WordPress**: Add a Custom HTML block, or use a plugin like GiveWP, WP Simple Pay, or Donorbox.
- **Squarespace**: Use a Button block, or an Embed/Code block. Squarespace also has built-in donation options on some plans.
- **Wix**: Use Wix's "Donations" app, or add a Button element linked to your payment URL.
- **Shopify**: Create a "donation" product, or use a donation app.

## 3. Tips
- Put the button in your header/nav and again at the end of relevant pages.
- Offer suggested amounts and a recurring option.
- Check fees. They typically run around 2–3% plus a fixed fee, and some platforms add their own.
- If you're a registered nonprofit, make sure receipts are issued and your tax-deductible status is stated. If you're an individual or for-profit, don't imply donations are tax-deductible.
- Check local rules. Some places require registration for fundraising.
