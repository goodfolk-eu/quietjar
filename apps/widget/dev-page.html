QuietJar widget

The floating icon in the corner is the widget. Hovering it reveals a close control; closing it hides the widget for the rest of the browser session.

Config is set on window.QuietJar in dev-config.json:

window.QuietJar = __CONFIG_PRETTY__;

Edit dev-config.json, dev-page.html, or anything in src/ and the page reloads automatically.
